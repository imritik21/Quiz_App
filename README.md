# Simple Quiz App

This is a simple Quiz App project that allows users to play a quiz and know their score. The project is written in Java and is hosted on GitHub.

## Main Function Points
- Allows users to play a quiz
- Displays the user's score after the quiz is completed

## Technology Stack
- Java

## Features
- **2D Array for Storing Questions and Answers**: The quiz questions and answers are stored in a 2D array, which allows for efficient storage and retrieval of quiz data.
  
```java
// Example of how questions and answers are stored in a 2D array
String[][] questionsAndAnswers = {
    {"Question 1", "Answer 1"},
    {"Question 2", "Answer 2"},
    {"Question 3", "Answer 3"},
    // Add more questions and answers as needed
};
